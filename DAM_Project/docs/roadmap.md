# DAM Roadmap

This document outlines the planned phases of the DAM project.

## Short-term

* Unify the repository structure (this commit).
* Develop an MVP with basic auction and proof‑of‑efficiency features.

## Mid-term

* Integrate useful work into the tensor miner.
* Expand the AI backend with advanced models for fraud detection and task matching.

## Long-term

* Launch on mainnet with enterprise adoption.
* Incorporate support for gaming consoles and consumer hardware as compute nodes.
