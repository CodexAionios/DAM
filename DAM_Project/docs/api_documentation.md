# DAM API Documentation

This document will describe the APIs exposed by the DAM node and backend
services.  It is currently a placeholder.

## Node API

* `GET /tasks` – List available tasks.
* `POST /submit` – Submit a completed task result.

## Backend API

* `POST /match` – Match a task to a node.
* `POST /report` – Submit efficiency and fraud reports.
